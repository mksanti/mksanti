# Michael Santillán

I'm an Engineering Manager working across people, technology and business to help engineering teams make better decisions and deliver through change and complexity.

My background is in software engineering and open source. I've contributed to projects in the Vue and Nuxt ecosystems, including Buefy, Nuxt Buefy and Create Nuxt App.

- tools, systems and practical uses of AI.
